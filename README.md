# 三文鱼AI · 外贸运费快速测算工作台

面向制造外贸企业船务、物流采购与业务同事的运费预算演示工作台。输入产品、数量、包装、起讫地点、服务范围和货代方案，快速比较空运与海运整柜的总运费及每套运费，并导出可核对的测算资料。

## 适合怎样的工作

- 业务同事询问某个订单发往海外的大致运输成本。

- 现场展示如何把产品包装、装载规则和费率表连接成可操作的工作台。

这是可操作的预算 Demo。所有预置价格、产品主数据、包装规范、装载模板和预算汇率均有模拟标识。**预置运费不代表实时市场价、有效货代报价或可订舱承诺。**

## 计算逻辑

计算顺序为：

1. 订货数量换算成外箱，按包装规则处理尾箱。
2. 计算每层箱数、层数、满托和尾托，检查高度、重量及排布限制。
3. 使用交运外廓计算体积，累计产品、纸箱、托盘及缠膜的重量。
4. 按已配置的装载模板计算起运车次、派送车次与 FCL 柜数。
5. 空运按所选规则比较实际毛重与材积重，得到计费重量。
6. 按每板、每票、每车、每柜、计费重量等费用单位计算各服务段。
7. 先汇总各原币金额，再按保存的预算汇率折算，得出总预算和每套运费。

金额计算复用 Python `Decimal` 核心。演示补值与严格规则分开，补值不会改写原始费率有效期或把空价写成零。

预置标志碟标准包装的参考点：1000 套对应 63 托、101.64m³、4623kg、空运计费重量 16940kg。这是本例模拟包装的结果，不是其他货物的通用换算系数。柜数按本例装载模板计算，不用体积直接除以经验柜容。

## 线上使用与数据保存

Cloudflare 版使用相同的 Python 计算规则。每位访客的费率修改与测算记录保存在**当前浏览器的本地存储**，不与其他访客共用资料版本或记录列表。清除网站数据、更换浏览器或设备后，不会自动找回这些本地记录；需要留存时请导出 JSON 或其他文件。

进行测算和询价解析时，当前请求所需的资料会发送到本站 Cloudflare Worker 处理。PDF和Excel根据已保存快照在浏览器内生成并直接下载，避免免费边缘运行时对大文件排版的CPU限制。预置文件是公开模拟资料。请使用模拟或已获授权的业务资料；本 Demo 不提供企业账号、团队协同、跨设备同步或企业级数据管理。

资料源下载提供发布时的预置资料；修改后的个人资料应从当前工作空间导出，不能把预置下载包当成修改后的版本。

## 本地运行与部署

环境需要 Python 3.13 或以上、`uv`、Node.js，以及有效的 Cloudflare 账号授权。使用仓库的锁定依赖安装、构建和运行：

```sh
npm ci
uv sync
npm run build
uv run pywrangler dev --port 8877
```

在浏览器打开 `http://127.0.0.1:8877/?public_demo=1`。这个参数在本机启用公开版的访客独立存储适配；公网地址自动启用。`npm run build` 生成部署所需的 `worker/` 与 `dist/`，这两个目录不提交 Git。

`uv.lock` 为开发环境锁定了 `uv 0.13.6`。请通过项目环境执行 `uv run pywrangler`，让 Pywrangler 使用项目虚拟环境中的工具版本。

公开部署前先完成本地测算与文件导出检查，并在自己的 Cloudflare 账号完成 Wrangler 授权，然后执行：

```sh
uv run pywrangler deploy --dry-run
uv run pywrangler deploy
```

部署入口、依赖版本和静态资源配置以仓库中的 `pyproject.toml`、锁定文件及 Wrangler 配置为准。不要提交账号令牌、`.env`、运行数据库或客户原始文件。
